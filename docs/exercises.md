## 문제 1. 정체온도·정체압력 (고도 25 km, M 6)
1976 미국 표준대기에서 기하 고도 25 km의 정온·정압을 구하고, M = 6 비행 시 자유류 속도, 동압, 정체온도 T₀, 정체압력 p₀를 구하라.

<details><summary>풀이와 답</summary>

1. 지오퍼텐셜 고도: h = r₀z/(r₀+z) = 6,356,766×25,000/(6,356,766+25,000) = 24902.1 m (r₀ = 6,356.766 km).
2. 20–32 km 층: T = 216.65 + 0.001(h − 20,000) = **221.55 K**; p = 5474.889 (216.65/T)^(g₀M/(R*L)), g₀M/R* = 34.1632 K/km, L = 1 K/km → **p = 2549.2 Pa**, ρ = p/(RT) = 0.04008 kg/m³.
3. a = √(γRT) = 298.4 m/s → u = 6a = **1790 m/s**; 동압 q = ½γpM² = **64.2 kPa**.
4. T₀/T = 1 + (γ−1)/2·M² = 8.20 → **T₀ = 1817 K**.
5. p₀/p = (T₀/T)^(γ/(γ−1)) = 1579 → **p₀ = 4.02 MPa**.

단위: [p] = Pa, [ρ] = Pa/(J/(kg·K)·K) = kg/m³ ✓.
검산: 표준대기표 25 km 값 T = 221.55 K, p = 2549 Pa와 일치. M 6에서 T₀ ≈ 1817 K는 γ 일정 가정의 값이며 실제(열적 완전기체)보다 높다 — 계획 §5의 '완전기체 한계' 경고 대상 근처.
</details>

## 문제 2. 수직충격파 후 마하수·압력비
흡입구가 불시동되어 카울 앞에 수직충격파가 섰다고 보자. 문제 1의 자유류(M₁ = 6)에서 충격파 뒤 M₂, p₂/p₁, T₂/T₁, 정체압비 p₀₂/p₀₁을 구하라. 설계 마하 5에서도 같은 값을 구해 비교하라.

<details><summary>풀이와 답</summary>

- M₂² = [1 + (γ−1)/2 M₁²]/[γM₁² − (γ−1)/2]
- p₂/p₁ = 1 + 2γ/(γ+1)(M₁² − 1)
- ρ₂/ρ₁ = (γ+1)M₁²/[(γ−1)M₁² + 2], T₂/T₁ = (p₂/p₁)/(ρ₂/ρ₁)
- p₀₂/p₀₁ = (ρ₂/ρ₁)^(γ/(γ−1)) (p₁/p₂)^(1/(γ−1))

| M₁ | M₂ | p₂/p₁ | ρ₂/ρ₁ | T₂/T₁ | p₀₂/p₀₁ |
|---|---|---|---|---|---|
| 6 | **0.4042** | **41.83** | 5.268 | 7.941 | **0.0297** |
| 5 | 0.4152 | 29.00 | 5.000 | 5.800 | 0.0617 |

M 6, 25 km에서 충격파 뒤 정온 T₂ = 7.941 × 221.6 = 1759 K. 같은 방식으로 M 7은 약 2320 K로 **2000 K를 넘는다**(계획 §5 경고 조건).
검산: 수직충격파 표 M = 6: M₂ = 0.4042, p₂/p₁ = 41.83, p₀₂/p₀₁ = 0.02965; M = 5: 0.4152, 29.00, 0.06172와 일치. 모두 무차원 ✓.
</details>

## 문제 3. θ-β-M 관계 (M 2.5, θ 15°)
1단 램프 15°가 M 2.5 흐름을 꺾을 때 약한 경사충격파 각 β, 충격파 뒤 마하수 M₂, p₂/p₁, 정체압비를 구하라. 이 마하수에서 붙은 충격파가 가능한 최대 꺾임각도 구하라.

<details><summary>풀이와 답</summary>

tan θ = 2 cot β (M₁² sin²β − 1)/[M₁²(γ + cos 2β) + 2]를 β ∈ (sin⁻¹(1/M₁), β_max) 구간에서 이분법으로 풂.
- **β(약) = 36.94°**
- 법선 마하수 M_n1 = M₁ sin β = 1.5026 → p₂/p₁ = **2.468**, T₂/T₁ = 1.322, p₀₂/p₀₁ = **0.9290**
- M₂ = M_n2/sin(β − θ) = **1.874**
- 최대 꺾임각 θ_max = 29.80° (이때 β = 64.78°)

검산: 경사충격파 도표(NACA 1135 계열)에서 M 2.5, θ 15°의 약한 해 β ≈ 36.9°, θ_max ≈ 29.8°와 일치. I3 쐐기 검증(성공 기준: β, p₂/p₁ 1% 이내)의 기준값으로 쓸 수 있다.
</details>

## 문제 4. Kantrowitz 한계와 등엔트로피 한계 (M 2, 4, 6에서 A_t/A_i)
내부 압축 흡입구 입구 면적 A_i, 목 면적 A_t. (a) 등엔트로피 한계(시동된 흐름이 목에서 정확히 M = 1) A_t/A_i, (b) Kantrowitz 한계(입구에 수직충격파가 선 불시동 상태에서 자기시동 가능한 최소 A_t/A_i)를 구하라.

<details><summary>풀이와 답</summary>

- 면적-마하 관계 A/A* = (1/M)[2/(γ+1)(1 + (γ−1)/2 M²)]^((γ+1)/(2(γ−1)))
- (a) 등엔트로피: A_t/A_i = A*/A(M_i)
- (b) Kantrowitz: 입구 수직충격파 뒤 M₂에서 등엔트로피로 목까지 가속해 M = 1 → A_t/A_i = A*/A(M₂). 같은 값을 (A*/A)(M_i)/(p₀₂/p₀₁)로도 계산해 일치 확인(Kantrowitz & Donaldson 1945의 수축비 개념).

| M_i | M₂ | 등엔트로피 A_t/A_i | Kantrowitz A_t/A_i | (내부 수축비 A_i/A_t: 등엔트로피 / Kantrowitz) |
|---|---|---|---|---|
| 2 | 0.5774 | **0.5926** | **0.8220** | 1.688 / 1.216 |
| 4 | 0.4350 | **0.0933** | **0.6724** | 10.719 / 1.487 |
| 6 | 0.4042 | **0.0188** | **0.6342** | 53.180 / 1.577 |

해석: A_t/A_i가 Kantrowitz 값보다 크면 자기시동, 등엔트로피 값보다 작으면 시동된 흐름도 유지 불가(목 질식), 그 사이는 **이중해(시동/불시동 모두 가능) 구간 — 히스테리시스(Q2)가 생기는 범위**. M → ∞에서 M₂ → √((γ−1)/(2γ)) = 0.378이므로 Kantrowitz 한계 A_t/A_i → 0.600(γ = 1.4)에 수렴한다.
검산: 두 식의 Kantrowitz 값이 소수 15자리까지 일치(계산 내부 확인). M 2에서 A/A* = 1.6875는 등엔트로피 표와 일치.
</details>

## 문제 5. 회복온도 (층류·난류 회복계수)
문제 1의 자유류(M 6, 25 km) 평판에서 층류(r = Pr^½)와 난류(r = Pr^⅓) 회복온도 T_aw를 구하고, 벽 300 K 등온일 때 열이 어느 방향으로 흐르는지 말하라.

<details><summary>풀이와 답</summary>

T_aw = T∞[1 + r (γ−1)/2 M∞²]
- 층류: r = 0.71^½ = 0.8426 → **T_aw = 1566 K**
- 난류: r = 0.71^⅓ = 0.8921 → **T_aw = 1645 K**
- 비교: T₀ = 1817 K (r = 1)

T_w = 300 K < T_aw이므로 열은 **유체 → 벽**으로 흐른다. 이 프로젝트의 부호 규약(CLAUDE.md 규칙 3: 벽으로 들어가는 방향 양수)에서 q_w > 0.
검산: T_aw/T₀ = 0.905(난류)로 r에 가까움(고마하에서 T_aw/T₀ → r). 단위 K ✓.
</details>

## 문제 6. 레이놀즈 유사로 C_f에서 Stanton 수 추정
문제 1 자유류, 앞전에서 x = 1 m, 벽 300 K, 완전 난류로 가정한다. Van Driest II로 계산한 국소 마찰계수가 **C_f = 1.834e-03**일 때(아래 풀이에 계산 과정 첨부), Colburn 형 레이놀즈 유사 St = C_f/(2 Pr^⅔)로 Stanton 수와 벽 열유속 q_w = St ρ∞u∞c_p(T_aw − T_w)를 구하라.

<details><summary>풀이와 답</summary>

**(주어진 C_f의 출처 — Van Driest II, Hopkins & Inouye 1971 형식)**
- Re_x = ρ∞u∞x/μ∞ = 4.955e+06 (μ∞ = 1.448e-05, μ_w = 1.846e-05 Pa·s)
- A = [r(γ−1)/2 M² T∞/T_w]^½ = 2.1780, B = [1 + r(γ−1)/2 M²] T∞/T_w − 1 = 4.4821 (r = Pr^⅓)
- α = (2A² − B)/√(4A² + B²) = 0.8008, β = B/√(4A² + B²) = 0.7171
- F_c = (T_aw/T∞ − 1)/(sin⁻¹α + sin⁻¹β)² = 2.1504, F_Rθ = μ∞/μ_w = 0.7846, F_Rx = F_Rθ/F_c = 0.3649
- 비압축 등가: Re_x,inc = F_Rx Re_x = 1.808e+06; Kármán–Schoenherr 0.242/√C_f,inc = log₁₀(Re_x,inc C_f,inc) → C_f,inc = 3.9445e-03
- C_f = C_f,inc/F_c = **1.8343e-03**

**(문제의 답)**
- St = C_f/(2 Pr^⅔) = **1.1524e-03** (레이놀즈 유사 계수 2St/C_f = 1.256; 단순 레이놀즈 유사 St = C_f/2 = 9.1717e-04)
- q_w = St ρ∞ u∞ c_p (T_aw − T_w) = 1.1524e-03 × 0.04008 × 1790 × 1004.7 × 1345 = **112 kW/m²** (벽으로 들어감, 양수)

단위: [St ρ u c_p ΔT] = (kg/m³)(m/s)(J/(kg·K))(K) = W/m² ✓.
검산: Kármán–Schoenherr 식에 대입하면 좌변 0.242/√3.9445e-03 = 3.8532, 우변 log₁₀(1.808e+06×3.9445e-03) = 3.8532로 같다. I4에서 TMR `cf_vandriestII.dat`와 같은 식 계열인지 대조할 것.
주의: Re_x ≈ 5×10⁶은 극초음속 평판에서 천이 구간일 수 있다 — "완전 난류"는 문제를 위한 가정.
</details>

## 문제 7. Waltrup–Billig 의사충격파열 길이
아이솔레이터 입구 조건을 M₁ = 2.2, 높이(덕트 지름 대용) D = 20 mm, 입구 경계층 운동량 두께 θ = 0.4 mm, Re_θ = 2.0×10⁴로 둔다. 하류 압력비 p₂/p₁ = 2와 4일 때 충격파열 길이 s를 구하라. 이 M₁에서 정상 충격파 압력비까지 올릴 때의 s도 구하고, 아이솔레이터 길이 설계에 대한 의미를 말하라.

상관식(Waltrup & Billig 1973, 원형 덕트):
  s (M₁² − 1) Re_θ^¼ / √(D θ) = 50 (p₂/p₁ − 1) + 170 (p₂/p₁ − 1)²

<details><summary>풀이와 답</summary>

- √(Dθ) = √(0.020 × 0.0004) = 2.8284 mm = 0.002828 m
- (M₁² − 1) Re_θ^¼ = (4.84 − 1)(2×10⁴)^¼ = 45.666
- p₂/p₁ = 2: s = √(Dθ)(50·1 + 170·1)/45.666 = **13.6 mm** (s/D = 0.68)
- p₂/p₁ = 4: s = √(Dθ)(50·3 + 170·9)/45.666 = **104.1 mm** (s/D = 5.20)
- 정상 충격파 압력비 p₂/p₁ = 5.48 (M₁ = 2.2): s = **225 mm** (s/D = 11.3)

단위: 좌변 [s]·[무차원]/[m] = 무차원, 우변 무차원 ✓ → s는 √(Dθ)와 같은 길이 단위.
의미: 압력비가 커지면 s가 (p₂/p₁ − 1)²에 비례해 빠르게 늘어난다. 아이솔레이터가 s보다 짧으면 충격파열이 입구 목까지 밀려 불시동으로 이어진다(Q3, I10).
주의:
1. 상관식은 원형 덕트, 1.53 ≤ M₁ ≤ 2.72, D = 1.0–6.1 in, θ = 0.007–0.036 in 범위의 실험에서 얻었다(Waltrup & Billig 1973 초록). 이 문제의 D = 20 mm(0.79 in)는 범위보다 약간 작다.
2. 2D 직사각 아이솔레이터에 쓸 때 D를 높이로 둘지, 수력 지름으로 둘지는 문헌마다 다르다 → I10 비교 때 어느 쪽을 썼는지 명시.
3. 계수 50·170은 원문을 열람하지 못해 2차 인용 형태로만 확인했다(references.md R4). I10 전에 원문 식 번호를 확인할 것(CLAUDE.md 규칙 11).
</details>
