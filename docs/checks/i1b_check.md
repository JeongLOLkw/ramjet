## 4. 점검에서 나온 불일치·주의

1. **이전 I1 자료와 Science 후속의 충돌 없음**을 확인했으나, `references.md` T1의 "4판(Anderson & Cadou, 2021)"은 Science 후속이 "Anderson 단독"으로 바꿨다. 출처가 [검색 스니펫]뿐이라 정정은 **"단독 저자로 보임, 출판사 페이지 기준 [검색 스니펫]"** 수준으로만 반영한다.
2. Settles 벽 조건 "1.05·T₀"는 [2차 1건, 미확정]. 이를 케이스 설정에 넣는 것은 사용자 결정 사항(i1b §7-1)이고 이 점검에서 정하지 않는다.
3. Settles 경계층 측정 위치가 두 출처에서 −63.5 mm(Oliver 2006 Table 5)와 −50.8 mm(Oliver 2007 Table 1)로 다르다. 어느 쪽이 맞는지 이 점검으로 판단할 수 없다.
4. W&B 직사각 변형(Re_θ 지수 ¼ vs ⅕)은 결론이 안 났다. I10에서 쓰기 전에 사용자 결정(i1b §7-4) 필요.
