## 결론

**"RUN 21의 쐐기각은 12.5°" 주장은 맞다.** (원문만으로 판정 가능)

- Table 11의 δ 열에는 런 10–30이 전부 10으로 인쇄돼 있다(주장대로). 같은 표에서 런 9, 31, 32는 0이다.
- 그러나 그림 82 캡션, 그림 81 캡션, 그림 목록(xii쪽), 본문 114쪽이 모두 런 21의 δ = 12.5°로 적고 있다. 표의 δ 열은 이 런들에서 본문·그림과 어긋난다.
- 따라서 "표의 δ 열이 오식"이라는 판단은 합리적이다. 다만 원문 어디에도 오식이라고 명시한 곳은 못 찾았다(정오표 쪽은 확인하지 못함). 표 값과 본문이 충돌한다는 사실만 확정이고, 어느 쪽이 맞는지는 본문 쪽 증거의 수(그림 캡션 2개, 그림 목록, 본문 서술, 모든 도면이 일관)로 판단한 것이다.

### validation_data.md §3 서술과 다른 점 (수정은 메인 세션 몫)
1. "본문에서 런 21–26 = 12.5°, 27–29 = 15°"로 적혀 있는데, 그림 캡션으로는 **런 27–30 = 15°** (런 30도 15°). 런 23은 없음.
2. "Table 11에는 모든 런이 10으로 인쇄"는 런 10–30에 대해서만 맞다. 런 9, 31, 32는 0 (쐐기 없음으로 보임).
3. 부가 관찰: 본문 114쪽은 Mach 8.0 최대 열전달 증폭을 10.14 (Fig. 82)라고 쓰는데, 부록 E RUN 21 표의 최대 Q/Qo는 9.52, 그림 82에서도 약 9.5로 읽힌다. 10.14가 다른 정규화·보정 때문인지, 다른 런인지 원문만으로는 **판단 불가**. 검증 기준을 q/Q₀ = 9.52(표 값)로 쓰는 데는 지장이 없으나, 논문 본문의 10.14와 섞어 인용하지 말 것.
